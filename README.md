# StickerSmash – Gestos con Expo

Proyecto realizado siguiendo el tutorial oficial de Expo Gestures.

## 🎯 Funcionalidad

- Doble tap sobre el sticker → agranda o achica
- Drag → permite mover el sticker por la pantalla

## 🛠️ Tecnologías

- Expo
- React Native Gesture Handler
- React Native Reanimated

## 🚀 Cómo correr el proyecto

```bash
git clone https://github.com/torr3srolon-spec/StickerSmash-Gestos.git
cd StickerSmash-Gestos
npm install
npx expo start
